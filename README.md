## 🪷 Overview

Welcome to the personal portfolio of **Emanuel Okoth** (`@14Emanuel`), based in **Kisumu, Kenya**.

This portfolio presents a deliberate departure from standard generic templates:
1. **Unapologetic AI Agent Specialization**: Clear, technical articulation of multi-agent cognitive loops, tool calling, persistent state graphs, and evaluation guardrails.
2. **Systems-Level Algorithmic Rigor**: Rooted in Zone01 Kisumu's peer-to-peer engineering culture, writing high-performance Go, discrete graph flow algorithms, and low-level stack optimizers.
3. **Real-World Frontier Impact**: Deploying offline-first USSD/SMS labor dispatch via Africa's Talking, computer vision fabric opacity analysis, and climate-smart agricultural telemetry in the Lake Victoria basin.
4. **The Sunlit Pond & Water Lilies Theme**: A radiant, pristine aquatic design featuring interactive canvas water ripples, floating lily pads, and an executive **"Cognitive Leap" frog metaphor** (Perceive &rarr; Leap &rarr; Verify &rarr; Settle).

## 🚀 Key Features

* **Interactive Agent Pond Simulator**: Test real-world agentic workflows (*Dispatch Construction Crew via USSD*, *lem-in Ant-Colony Flow*, *Fabric Drape & Opacity Vision*) across verified stepping-stone lily pads with a live execution stream.
* **Curated Project Showcase**:
  * **[Yaya AI Engine & Agent Pipeline](https://github.com/14Emanuel/yaya-ai-engine)** — AI job-matching algorithm & automated multi-channel growth subagents.
  * **[Kitabu Digital (MealCreditTracker)](https://github.com/14Emanuel/kitabu-digital)** — Construction site double-entry meal credit ledger system.
  * **[lem-in](https://github.com/14Emanuel)** — Ant-colony network flow and disjoint shortest-path algorithm in Go.
  * **[Fabric Match AI](https://github.com/14Emanuel/fabric-match-ai-algo)** — Computer vision and attribute reasoning algorithm evaluating garment drape, opacity, and silhouette.
  * **[PowerSmart Kenya & KijaniSpace](https://github.com/14Emanuel)** — IoT energy and climate-smart agriculture telemetry.
  * **[push-swap](https://github.com/14Emanuel/push-swap)** — Algorithmic two-stack sorting benchmark in Go.
* **"In The Field" Documentary Gallery**: Interactive photo showcase of field work, hackathon defense at Africa's Talking, Zone01 cohort, and Lake Victoria roots.
* **Cloud Firestore Backend**: Live contact inquiry desk saving visitor messages directly into Firestore `inquiries` collection.
* **Firebase Object Storage**: Managed image pipeline for portfolio media.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/14Emanuel/emanuel-portfolio.git
cd emanuel-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:3000 in your browser
```

### Static Export & Build

```bash
# Produce optimized production build in /out
npm run build
```
